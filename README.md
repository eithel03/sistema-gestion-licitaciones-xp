# Sistema de Gestión de Licitaciones

Proyecto final del curso Metodologías Ágiles de Desarrollo de Software de la Universidad Técnica Nacional.

## Descripción

Aplicación web modular para administrar licitaciones, proveedores, ofertas económicas, niveles de aprobación y tipos de cambio entre colones costarricenses y dólares estadounidenses.

## Metodología

El proyecto se desarrolla exclusivamente mediante Extreme Programming (XP), aplicando:

- Planning Game.
- Historias de usuario.
- Iteraciones cortas.
- Programación en parejas.
- TDD.
- Integración continua.
- Diseño simple.
- Refactorización.
- Pequeñas liberaciones.
- Propiedad colectiva del código.

## Arquitectura

Se utilizará una arquitectura de monolito modular.

## Tecnologías previstas

- .NET 9.

- ASP.NET Core Web API.
- Entity Framework Core 9.
- PostgreSQL 16.
