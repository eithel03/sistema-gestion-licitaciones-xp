# Flujo de trabajo con Git y GitHub

## Rama principal

La rama principal del proyecto es `main`.

No se desarrollarán funcionalidades directamente en `main`.

## Ramas

- `feature/HU-XX-descripcion`
- `chore/descripcion`
- `docs/descripcion`
- `test/descripcion`
- `fix/descripcion`
- `refactor/descripcion`

## Commits

Se utilizarán mensajes descriptivos basados en Conventional Commits:

- `feat`: nueva funcionalidad.
- `test`: pruebas.
- `fix`: corrección.
- `refactor`: mejora interna.
- `docs`: documentación.
- `chore`: configuración o mantenimiento.

## Integración

1. Crear una rama.
2. Trabajar mediante programación en parejas.
3. Crear commits pequeños.
4. Ejecutar pruebas disponibles.
5. Subir la rama.
6. Crear Pull Request.
7. Verificar GitHub Actions.
8. Realizar revisión conjunta.
9. Integrar a `main`.
